# Heather Sweeney Designs (HSD) – SQL Server Database Case Study

## Overview
A relational database project implemented using **Microsoft SQL Server (T-SQL)** to manage customers, seminars, contacts, products, and invoices for an interior design business.

## Technologies
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL

## Database Structure
The database consists of seven related tables:

- `CUSTOMER`
- `SEMINAR`
- `SEMINAR_CUSTOMER`
- `CONTACT`
- `PRODUCT`
- `INVOICE`
- `LINE_ITEM`

## Implementation
The project covers:

- Database and table creation.
- Primary keys, foreign keys, and constraints.
- Data insertion and manipulation (`INSERT`, `UPDATE`, `DELETE`).
- SQL queries using filtering, joins, subqueries, and aggregate functions.
- Views and user-defined functions.
- Referential integrity and transactions.

## How to Run
1. Install Microsoft SQL Server and SSMS.
2. Open the SQL scripts in SSMS.
3. Execute the scripts in the following order:
   - Create Database
   - Create Tables
   - Insert Data
   - Run Queries
   - Create Views and Functions

## Learning Outcomes
- Understanding relational database design.
- Working with table relationships and constraints.
- Writing SQL queries to retrieve and analyze data.
- Creating views and user-defined functions.
